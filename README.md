# Dust-Scattering Halos and Gravitational-Wave Counterpart Localization

Monte-Carlo forward model and maximum-likelihood localization for Galactic
dust-scattering halos produced by X-ray flashes from gravitational-wave
sources. Independent undergraduate research extending Nederlander & Paerels
(2020, [ApJ 890, 135](https://doi.org/10.3847/1538-4357/ab6dc5)).

**Status: working draft, circulated for discussion. Not submitted.**

**Correction (28 September 2026).** Earlier versions drew photons from each
dust screen in proportion to its optical depth alone. The physical rate at a
given epoch carries an extra factor 1/d, because a screen at distance d
spreads its photons over delays proportional to d, so near screens were
under-weighted (the 60 pc screen of the fiducial sightline by a factor
400/60 ≈ 6.7 relative to the 400 pc screen). The simulator and the likelihood
template are fixed, `code/test_yields.py` checks them, and every result that
uses more than one screen has been regenerated (Table 1's three-screen
column, Figures 2, 3 and 5–8, Sections 3.2 and 3.5–3.8; Figure 3's
three-screen points were missed on 28 September and regenerated on
1 October). Single-screen results were unaffected. The conclusions stand: the multi-screen localization numbers
moved within Monte Carlo noise, the tomography is unchanged, and the
realistic sightline of Figure 7 now recovers its nearby clouds, which the old
weighting had suppressed. Seeds for the regenerated runs: 2809 (Table 1),
2810 (self-calibration), 2811 (ensemble).

## Summary

NP20 proposed that a prompt X-ray flash from a gravitational-wave source will
scatter off Galactic dust into an expanding ring-shaped halo whose geometric
center marks the source, and estimated a localization of order 1″–10″ without
constructing an explicit algorithm. This work supplies the algorithm and
quantifies the achievable precision for realistic, clumpy sightlines:

- **Localization** scales as `2σ_r/√N` — the Cramér–Rao bound set by the ring
  width — reaching ≈1″ for a few hundred detected halo photons, with a
  maximum-likelihood estimator that saturates the bound.
- **No dust prior is needed.** A self-calibrating estimator using only the
  concentricity of the rings recovers the source without any model of the
  foreground dust.
- **Halo tomography.** The same rings measure the distances to the
  intervening dust screens (60/150/400 pc recovered as 60/151/403 pc).
- **Robustness.** Results survive a realistic eight-cloud sightline (median
  1.25″ over a 50-sightline ensemble), soft X-ray background, and the loss
  of all dust prior information.
- **Detection.** A matched-filter analysis shows the ring is a >5σ feature
  for a few tens of photons, with only a logarithmic trials penalty across a
  tiled all-sky search.

## Contents

```
paper.md          paper source (Markdown + LaTeX math) — single source of truth
paper.pdf         typeset PDF
Makefile          one-command rebuild (see below)
build.sh          rebuilds paper.tex / paper.pdf from paper.md
requirements.txt  pinned Python dependencies (pip)
environment.yml   the same, as a conda environment
figures/          the 11 figures, all generated by code/
results/          Monte-Carlo outputs (JSON)
code/             simulation and analysis code (NumPy only; Matplotlib for figures)
```

Every figure and every quoted number in the paper is produced by running the
code in `code/`. No external data or network access is required.

## Requirements

Python 3.10 with NumPy and Matplotlib, at the versions pinned in
`requirements.txt` (or `environment.yml` for conda). Rebuilding the paper
additionally needs `pandoc` and `pdflatex`.

## Reproducing the results

```sh
pip install -r requirements.txt   # or: conda env create -f environment.yml
make            # all figures and paper.pdf, from the stored results (~2 min)
make test       # unit test for the photon yields + ring-geometry checks
make results    # rerun every Monte Carlo from scratch (~10 min; overwrites results/)
```

Every figure script fixes its random seed, so `make` reproduces the committed
figures exactly from the stored results. `make results` reproduces the
multi-screen runs, the detection fractions and the calibration run exactly;
the original seeds of the single-screen Table 1 columns, the single-screen
self-calibration and the background sweep were not recorded, so those
reproduce within Monte Carlo noise. The Makefile lists every command.

To run individual steps, run the scripts from inside `code/`. They import the
shared module `halo.py`, read/write JSON in `../results/`, and write figures to
`../figures/`.

**Core module**

- `halo.py` — physics (ring geometry, scattering cross section), the
  forward-model simulator, the maximum-likelihood and self-calibrating
  localizers, tomography, and the realistic-sightline / grain-size samplers.

**Monte-Carlo data** (write to `../results/`)

- `mc_accumulate.py run <cfg> <K> <seed>`, then `finalize` → `mc_results.json`;
  accumulates the Table 1 trials in chunks and keeps every individual trial in
  `mc_acc_<cfg>.json`, so the table can be recomputed from the raw values
  (K = 120 per photon count in the paper)
- `selfcal_mc.py run <single|multi> <K> <seed>`, then `finalize` →
  `selfcal_results.json` (raw trials kept in `selfcal_acc_<cfg>.json`)
- `detect_mc.py <bkg> [K]` → `detect.json`
- `vsbkg_smooth.py <seed> [K]` → `vsbkg_acc.json` (accumulates)
- `calib.py` → `calib.json` (bias / coverage)
- `ensemble_sightlines.py <K> <seed>`, then `report` → `sightline_ensemble.json`
  (the 50-sightline ensemble of Section 3.7)
- `matched_filter.py` → `matched_filter.json` + Figure 10

**Figures** (write to `../figures/`)

- `make_fig1_2.py` → Figs 1–2 (single screen; three screens)
- `crb_feasibility.py` → Figs 3, 11 (Cramér–Rao scaling; feasibility)
- `plot_fig4.py` → Fig 4 (localization vs background)
- `make_new_figs.py` → Figs 5–6 (self-cal vs template; tomography)
- `fig7_realistic.py` → Fig 7 (realistic 8-cloud sightline)
- `fig8_time_evolution.py` → Fig 8 (ring expansion vs time)
- `fig9_plot.py` → Fig 9 (detectability; run `detect_mc.py` first)
- `matched_filter.py` → Fig 10 (matched filter and trials factor)

**Utility**

- `sanity_check.py` — ring-geometry checks against the values quoted in the
  paper.
- `test_yields.py` — unit test for the relative photon yields of screens at
  different distances, in the simulator and the likelihood template.

Figures that depend on Monte-Carlo data assume the relevant JSON already
exists in `../results/`; run the corresponding data script first.

## Rebuilding the paper

```sh
make paper      # or: bash build.sh  -> paper.tex, paper.pdf
pandoc paper.md -o paper.docx
```

The build script runs pandoc, strips the manual figure/table labels so LaTeX
auto-numbers them, starts the appendix, and compiles the PDF.
